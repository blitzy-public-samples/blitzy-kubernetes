# Python test-tier dependencies for the pytest suite that ports the Go
# security-regression surface (V1-V8).
#
# AAP  §0.6.1.1 (Python Test Stack)  /  tech-spec §6.6.1 (test tiers)
#
# Every version below is an EXACT pin. Do not relax a pin without re-reading
# the rationale recorded in AAP §0.3.4 / §0.6.1.4:
#   * pytest is pinned to 9.1.1 (NOT 9.1.0): 9.1.0 regressed loading of
#     initial conftest.py files under the invocation directory.
#   * kubernetes is pinned to 34.1.0 - the exact-minor match for the
#     v1.34.0-blitzy server under test. Client 36.x sits in the partially
#     supported (+-) compatibility cell, and 36.0.0 shipped a defect that
#     dropped the Authorization header (fixed in 36.0.1) - precisely the
#     defect class the V1/V4/V7 parity tests exercise.
#   * etcd3gw is used for the raw ciphertext-at-rest read (V3): legacy
#     `etcd3` tops out at 0.12.0 and is unmaintained.
#
# Install (from the repository root):
#   source hack/lib/python.sh && kube::python::install
# or directly:
#   python/.venv/bin/python -m pip install -r python/requirements-test.txt
